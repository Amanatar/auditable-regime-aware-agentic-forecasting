# Pretrained Time-Series Foundation Models for Financial Return Forecasting

- **Authors:** Miquel Noguer i Alonso; Rodolfo Pereira Franklin
- **Year / venue:** 2026; arXiv
- **URL / DOI:** https://arxiv.org/abs/2606.27100
- **Method summary:** Benchmarks pretrained TSFMs against train-from-scratch models under equalized context and rolling-origin evaluation.
- **Datasets:** AAPL, AMZN, GOOG, JPM, META daily returns.
- **Key reported result:** TSFMs won 8/10 task rankings, but gains over random walk were small and sparse; only two Diebold–Mariano tests rejected equal/inferior accuracy.
- **Author-stated limitation or scope boundary:** Five equities only; no universal alpha claim, transaction costs, or live deployment test.
- **Sub-topic:** financial TSFM evaluation
