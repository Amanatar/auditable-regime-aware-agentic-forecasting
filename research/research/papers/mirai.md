# MIRAI: Evaluating LLM Agents for Event Forecasting

- **Authors:** Chenchen Ye et al.
- **Year / venue:** 2024; arXiv
- **URL / DOI:** https://arxiv.org/abs/2407.01231
- **Method summary:** Introduces APIs for retrieving structured events and news before predicting future international events.
- **Datasets:** GDELT-derived relational event tasks and historical news.
- **Key reported result:** Evaluates source integration, code/tool use, and temporal event reasoning across horizons.
- **Author-stated limitation or scope boundary:** Targets international events rather than financial returns; no economic utility test.
- **Sub-topic:** event forecasting benchmarks
