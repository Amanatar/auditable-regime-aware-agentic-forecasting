# Survey protocol

This survey covers 21 papers spanning agentic forecasting, financial TSFM evaluation, distribution shift, uncertainty calibration, and backbone models. The initial breadth target was the default 40 papers. After 21 papers, the same four limitations repeated—temporal leakage/contamination, poor calibration under shift, weak economic evaluation, and lack of evidence provenance—without a new sub-topic, so the diminishing-returns stopping rule was applied.

The project direction is **auditable, contamination-resistant, regime-aware agentic forecasting under financial distribution shifts**.
